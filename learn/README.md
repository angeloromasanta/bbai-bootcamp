# Lessons

One folder per topic, made by the `learn` skill:

```
<your-topic>/
    notes.md        where you started, the map, each step, your answers, where you stopped
    screens/        every screen of the lesson, in order
    sims/           the simulations; each opens on its own with a double-click
```

Reread `notes.md` before an exam. Next time you say "teach me …" on the same topic, the
agent reads it and carries on from where you stopped.

To replay a finished lesson, open `lesson.html#<your-topic>` (the page address, then
`#` and the folder name).
